# cover-xiaohongshu

一个帮你做小红书封面的 Codex / Claude Skill。唤醒词：**小红书封面**。

你可以把文章、选题、产品截图或参考封面丢给它。它会帮你想标题、拆构图、定画面重点，最后给出一段能直接拿去生成图片的 prompt；在 Codex 里也可以直接调用图片生成能力出封面图。你也可以持续喂给它不同样图，让它把好用的排版方法沉淀下来，后续生成更丰富、不容易撞款。

简单说，它适合三件事：

- **从文章生成封面**：不知道封面怎么做时，让它帮你定标题、风格和画面。
- **扩充排版库**：上传优秀样图，让它提炼排版方法，增加后续生成的多样性。
- **参考样图重做**：借鉴样图的排版思路，但换成你的主题和内容。

## 怎么用

最简单的用法：

```text
小红书封面，帮我给这篇文章做一张封面：
这里粘贴文章内容……
```

只想要提示词：

```text
小红书封面，给我一段可以直接跑图的 prompt。
主题是：AI 写作效率提升。
```

想直接出图：

```text
小红书封面，直接帮我生成一张封面图。
主题是：再见了 Figma。
风格要有冲击力，标题要短。
```

想用样图扩充排版库：

```text
小红书封面，拆解这张封面的排版方法：
1. 标题区、主体区、装饰元素分别怎么安排？
2. 这种排版适合什么类型的选题？
3. 把它沉淀成一个可复用的排版方案。
```

想参考样图重做：

```text
小红书封面，参考这张样图的构图和标题层级，
但主题换成「AI 写作效率提升」，不要照抄原图元素。
```

## 它会帮你想什么

你不需要一开始就懂设计。它会按需追问，比如：

- 封面要偏专业、情绪化，还是更有冲突感？
- 要不要真人出镜？
- 有没有产品截图、UI 图、品牌图可以放进封面？
- 标题要更短更狠，还是更清楚说明价值？
- 想做成极简、产品主视觉、对比卡片，还是海报拼贴？

如果你什么都不确定，也可以直接说：

```text
你来判断，给我一个适合小红书点击的方案。
```

---

## 样图拆解能做什么

上传一张小红书封面样图后，它不是只给你做“好不好看”的点评，而是把样图里的排版方法拆出来，补充到可复用的排版库里。

它会重点看：

- 标题区放在哪里，占多大面积
- 主体是人物、产品、截图，还是文字本身
- 前景、中景、背景怎么分层
- 哪些装饰元素能增强信息层级
- 这种排版适合什么类型的选题
- 以后生成封面时，如何把它变成一个新的排版选项

它的目标不是复刻某一张图，而是不断丰富“可选排版方案”。样图越多，后续生成时可选的构图和标题布局就越丰富。

## 常用风格

| 风格 | 适合什么 |
|------|----------|
| 深色冲击风 | 强情绪、强反差、想让人一眼停住 |
| 纯色扁平风 | 干净、清爽、教程类或工具类内容 |
| 产品主视觉风 | 有产品图、UI 截图、网页截图时 |
| 对比卡片风 | 前后对比、好坏对比、改版对比 |
| 极简留白风 | 高级感、观点类、短标题 |
| 海报拼贴风 | 素材多、信息密度高、想做层次感 |
| 人物侧置风 | 有真人头像，另一侧留给大标题 |
| 背影构图风 | 情绪、成长、启发类内容 |
| 局部出镜风 | 只露手、半张脸，突出产品或动作 |
| 正面对视风 | 人物直视镜头，适合强观点和强表达 |

## 三种输出方式

| 你想要 | 它会怎么做 |
|--------|------------|
| 只要 prompt | 输出一段可以复制到图片模型里的封面提示词 |
| 直接生成图 | 先写好 prompt，再调用 Codex 图片生成能力 |
| 更适合发布 | 优先做无字底图，再用更稳定的方式叠清晰中文标题 |

---

## 参考图怎么给

可以给一张，也可以给多张：

- **图1**：人物照片，用来保持五官和出镜感觉
- **图2 起**：产品图、UI 截图、网页截图、品牌素材、想参考的封面样图

没有参考图也可以用。直接说“无参考图，直接做”，它会根据主题生成方案。
