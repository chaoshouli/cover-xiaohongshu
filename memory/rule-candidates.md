# Rule Candidates

Candidate rules live here before they are promoted into references.

Promotion threshold:

- 3 similar observations: candidate rule.
- 5-10 stable observations: promote to references.
- Strong expert prior: candidate immediately, but mark evidence as expert prior.

## Candidate: 大字贴纸冲击封面

Evidence:
- 多张亲子、宝宝、辅食、旅行样图都使用超大中文标题，标题占画面约 40%-60%，人物或主物压在标题前形成遮挡层次。
- 字体多为白色粗笔刷、厚重黑体或手写涂鸦体，并配深色描边、投影或粗糙边缘，手机端远看仍能识别。
- 背景常被虚化或弱化，第一注意力稳定落在标题和人物上。

Rule:
当内容属于亲子、教程、生活记录、避坑、攻略、强结论或情绪明确的封面时，优先尝试“虚化场景背景 + 人物/主物白边抠图 + 4-10 字巨大标题 + 少量小字补充”的结构。标题应短、粗、具体；人物或主物可遮挡标题边缘制造层次，但不能遮挡关键字。

Status: observing

## Candidate: 旅行城市手账拼贴

Evidence:
- 香港、北京 citywalk、周末 citywalk 样图都把地标、交通、美食、人物和局部照片拼成旅行手账式画面。
- 画面常用白色描边抠图、手绘箭头、虚线、定位图标、爱心和星星，把多个素材串成路线感。
- 标题以手写大字或粗体大字叠加在场景上，信息密度高但仍围绕“城市/路线/打卡”一个主题。

Rule:
当内容属于 citywalk、城市攻略、旅行路线、打卡合集、周末计划时，优先尝试“城市背景大图 + 地标/美食/交通小素材拼贴 + 人物白边抠图 + 手写路线感标题 + 箭头虚线”的结构。素材多时要用路线、分区或白边统一视觉秩序，避免变成无主次素材堆叠。

Status: observing

## Candidate: 暖调生活方式氛围封面

Evidence:
- 居家运动、高级感穿搭、心灵充电样图都使用暖调光线、右侧或下方人物、左侧手写标题和顶部细节小图。
- 标题配色常为白色、奶黄、草绿，配手绘下划线、星星、爱心等轻装饰，情绪更偏种草和陪伴感。
- 顶部 2-3 张细节小图提供生活证据，如早餐、运动器材、包鞋、书本、茶杯。

Rule:
当内容属于穿搭、居家运动、自律、情绪疗愈、vlog、生活方式种草时，优先尝试“暖调生活场景 + 人物白描边 + 顶部细节拼图 + 左侧手写大标题 + 小装饰符号”的结构。人物表情应放松、微笑或沉浸，标题要强调结果感和情绪收益。

Status: observing

## Candidate: 海报框架知识封面

Evidence:
- 北京文化样图用明显白色框架、顶部标题区、角落地点标签和底部说明，把照片变成更正式的设计海报。
- 信息层级比手账拼贴更规整，适合表达教程、设计方法、文化主题或系列感内容。
- 框架能把复杂实景压成一个可控视觉容器，降低背景抢注意力的风险。

Rule:
当内容属于设计教程、知识型内容、城市文化、系列课程或需要“专业感”的封面时，可尝试“主体大图 + 白色图形框架 + 顶部标题栏 + 角落标签 + 底部说明”的结构。标题字体应更规整，少用过多手绘装饰。

Status: observing

## Candidate: 拼图留白氛围封面

Evidence:
- 户外徒步样图使用 3-4 张照片分区拼接，文字很少，主要靠照片氛围和人物自拍建立记忆点。
- 人物照片破格压在拼图交界处，少量英文手写字增加随性感。
- 这种结构更适合 moodboard 和合集，而不是强干货标题。

Rule:
当内容属于户外、摄影、穿搭合集、旅行 moodboard 或以视觉氛围为主时，可尝试“3-4 张氛围照片拼接 + 人物自拍破格覆盖 + 少量手写英文/中文”的结构。标题不宜过长，画面应保留照片呼吸感。

Status: observing
